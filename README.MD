## Environment Variables

This project requires a [Supabase](https://supabase.com) project. Create a `.env` file in the root directory with the following variables:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_KEY=your_supabase_anon_key
```

| Variable | Description |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Your Supabase project URL (found in **Project Settings → API**) |
| `NEXT_PUBLIC_SUPABASE_KEY` | Your Supabase anonymous/public API key (found in **Project Settings → API**) |
